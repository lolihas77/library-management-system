1. Business Idea

The Library Management System is designed to manage books, library members, borrowing transactions, and book returns.

2. Problem Statement

Manual library management can lead to lost records, duplicated information, and difficulties in tracking borrowed books. This system aims to make library operations more organized and efficient.

3. Project Scope

The system covers book management, member registration, borrowing books, recording due dates, and managing book returns. The project focuses on designing a UML class diagram rather than developing a complete application.

4. Main Classes

- Book: Stores book details and availability status.
- Member: Stores library member information.
- Loan: Records borrowing dates, due dates, and return status.
- Librarian: Manages books, registers members, and records loans.
